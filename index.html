EL PROYECTO

Iluminación que responde.

IRTRAIlumina combina sensores y componentes electrónicos para crear un sistema capaz de reaccionar ante diferentes situaciones del entorno.

FUNCIONAMIENTO

¿Cómo funciona?

El sistema utiliza diferentes entradas para determinar cuándo debe activar la iluminación o generar una alerta.

☀
01

Fotoresistor

Detecta la cantidad de luz presente en el ambiente. Cuando la iluminación disminuye, el sistema puede activar el LED RGB.

DETECCIÓN DE LUZ
◉
02

Sensor PIR

Detecta movimiento o presencia de personas y permite activar la iluminación cuando alguien se encuentra dentro del área.

DETECCIÓN DE MOVIMIENTO
!
03

Push Button

Al presionar el botón se activa un buzzer, funcionando como una representación de un botón de alerta o emergencia.
