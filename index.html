01 / CONCEPTO

Iluminación que responde.

IRTRAIlumina propone un sistema capaz de detectar las condiciones del entorno y la presencia de personas para controlar automáticamente la iluminación. De esta manera, la tecnología se adapta al espacio en lugar de funcionar de manera constante.

03 / FUNCIONAMIENTO

Tres entradas.
Una respuesta inteligente.

El sistema utiliza diferentes sensores y controles para determinar cuándo debe actuar.

01

Fotoresistencia

Detecta la cantidad de luz ambiental. Cuando la iluminación disminuye, el sistema activa la iluminación.

LDR / LUZ
02

Sensor PIR

Detecta movimiento y presencia de personas, permitiendo activar la iluminación cuando alguien se encuentra en el área.

PIR / MOVIMIENTO
03

Botón de alerta

Permite activar el buzzer manualmente, funcionando como un mecanismo de alerta para situaciones que requieran atención.
