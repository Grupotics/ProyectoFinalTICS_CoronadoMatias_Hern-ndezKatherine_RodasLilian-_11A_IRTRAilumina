01 / LA IDEA

Iluminación que responde.

IRTRAIlumina utiliza sensores para detectar las condiciones del entorno y responder automáticamente.

Cuando la iluminación ambiental disminuye o se detecta movimiento, el sistema activa una luz LED RGB. Además, un push button permite activar un buzzer, funcionando como una representación de un botón de alerta o emergencia.

07 / IMPACTO

Innovación con propósito.

El proyecto busca demostrar cómo la automatización puede utilizarse para crear soluciones más eficientes y adaptadas a las necesidades de un entorno.

ODS 09

Industria, Innovación e Infraestructura

IRTRAIlumina propone una solución tecnológica basada en sensores y automatización para mejorar el funcionamiento de un sistema de iluminación.

ODS 13

Acción por el clima

La activación de la iluminación únicamente cuando se presentan determinadas condiciones puede contribuir a evitar el uso innecesario de energía.
